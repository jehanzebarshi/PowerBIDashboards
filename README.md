## 📊 Featured Dashboard: Retail Audit & Market Share

This interactive dashboard analyzes over **10,000 rows of retail store data**, sliced across multiple **time intelligence metrics** and **business dimensions**.

### 🔍 Key Features:
- Market share trends across time
- Store-level performance insights
- Dynamic filtering by region, brand, and time
- Intuitive visuals for stakeholder presentations
